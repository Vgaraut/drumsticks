# Task 009 — Basic PDF Export

## Goal

Add basic printable PDF/grid export.

## Requirements

PDF should include:

- project title;
- tempo;
- time signature;
- kit legend;
- grid rows;
- bar divisions;
- hit markers;
- velocity markers if easy.

## Constraints

- This is not professional music engraving.
- Do not block on standard notation.
- Validate project before export.

## Frontend integration

Add `Export PDF` button.

## Tests

- PDF generation does not crash;
- title/tempo appear;
- empty project/bar handled;
- grid includes instrument labels.

## Acceptance criteria

- User can export a readable printable PDF from a project.
