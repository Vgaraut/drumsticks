# 13 — Metrics and Pricing

## Validation metrics

Track these before optimizing revenue:

- time to first audible groove;
- projects created per user;
- exports per project;
- playback starts per project;
- percentage of users who edit after playback;
- AI patch preview rate;
- AI patch apply rate;
- MIDI export rate;
- PDF export rate.

## Activation event

A user is activated when they:

```text
create/open project -> add/toggle hits -> press play -> export or save
```

## Early qualitative validation

Test with 10–20 drummers.

Questions:

- Did they understand the grid without explanation?
- Did playback feel immediate enough?
- Did they want MIDI export?
- Did they want PDF export?
- Would they use it for practice, teaching, band work, or production?
- Did AI patching feel useful or annoying?

## Pricing hypothesis

Do not optimize pricing before workflow validation.

Potential later model:

### Free

- limited projects;
- default kit;
- basic MIDI/JSON export;
- limited AI patches.

### Pro

- more projects;
- more sound packs;
- PDF export;
- advanced AI patches;
- project sharing;
- user samples.

Potential price range:

- individual: $5–15/month;
- teacher/studio: $15–49/month depending on sharing/student features.

## Monetization expansions

- sound packs;
- teacher plan;
- shareable lessons;
- downloadable templates;
- official licensed packs later, only after traction.

## What not to monetize first

Do not block the core “write -> play” loop behind payment.

Charging before the user hears value will kill activation.
